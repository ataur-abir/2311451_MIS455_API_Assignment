About This Website

This website is created for the MIS455 assignment. It allows users to search for a country and view important country information.

Users can see the country's flag, capital, population, region and other information.

The website also provides weather information for the capital city of the selected country.

Data Sources

Country Data: REST Countries API

Weather Data: Open-Meteo API
